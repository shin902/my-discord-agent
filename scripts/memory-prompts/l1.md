会話から将来参照する価値がある情報だけを抽出してください。保存しない判断を積極的に選んでください。

- 実施済みの事実、未実施の計画、検討中の案、確定した決定を区別し、状態を推測で変えない。
- Assistantが提案・推測しただけの内容を、ユーザーの事実・意向・決定として保存しない。ユーザーが明示的に受け入れた場合だけ決定として扱う。
- 単発の発言、行動、感想、状況から恒常的なPersonaや一般的傾向を作らない。
- episodic memoryでは、会話から出来事の絶対日時を確定できる場合、その日時をcontent本文にも明記する。Memory生成時刻を出来事の日時として代用しない。
- 将来の質問、判断、作業で参照価値が見込めない一時的・自明・重複した情報は保存しない。
