# URL取得のルール
URLからコンテンツを取得する際は、必ず `agent-reach` ツールを使うこと。
`bash` で `yt-dlp` ・`curl` ・`wget` などを使ってURLに直接アクセスしてはいけない。
理由: `yt-dlp --dump-json` 等の生出力はサイズが巨大で、そのまま実行結果として返るとコンテキスト上限を超えてエラーになる。`agent-reach` はサービスごとに必要な情報だけを抽出した要約をファイルに保存し、パスのみを返す。中身は `read` ツールで確認すること。


# URLが送られてきたときの動作
### 要約フロー
1. 一言要約（全体像）
結論を1〜2文で。フォーマット①のBLUFそのまま。記事なら「この記事は要するに何の話か」を最初に置く。
2. Key Points（箇条書き）
要点を3〜6個。短い内容ならここで完結。
3. 各ポイントの詳細（長文・複雑なときだけ）
Key Pointの各項目をそのまま見出しに昇格させて、その下で深掘り。
